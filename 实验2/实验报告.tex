\begin{abstract}本实验在Dynamips中使用真实Cisco IOS完成PPP串口协商、DCE时钟配置、静态路由和跨网段互ping，并对PPP链路采集抓包。\end{abstract}
\section{实验要求与目的}
本实验验证路由器基本配置、串口PPP封装、DCE时钟和静态路由。重点不是把以太网链路替换成普通网线，而是从IOS输出确认Serial接口up/up、LCP Open、PPP封装和路由表中的下一跳。
\section{环境与设备}
拓扑包含R1、R2和两台VPCS模拟PC。R1使用Serial1/1作为DCE并配置clock rate 115200，R2使用Serial1/0作为DTE。PC1和PC2分别位于10.2.1.0/24与10.2.2.0/24，串口互联网段为10.2.12.0/30。Dynamips虚拟串口不需要实体DCE/DTE线缆。
\begin{figure}[H]\centering\includegraphics[width=0.96\textwidth]{截图/01-环境与拓扑预检.png}\caption{设备和链路验收摘要。}\end{figure}\clearpage
\section{配置思路}
先启动四个IOS实例，再配置两端以太网接口和串口地址；DCE侧设置时钟并启用PPP；随后在两台路由器上添加对端LAN的静态路由，在PC上设置默认网关。配置顺序先接口、后路由、再连通性，可以避免把路由缺失误判成PPP故障。
\begin{figure}[H]\centering\includegraphics[width=0.96\textwidth]{截图/02-PPP配置.png}\caption{R1串口PPP和DCE时钟配置。}\end{figure}\clearpage
\section{验证过程}
执行show interfaces Serial1/1、show interfaces Serial1/0确认line protocol up、Encapsulation PPP和LCP Open；执行show ip route确认静态路由；PC两方向各连续三轮ping，先预热ARP后统计正式结果，并采集PPP链路抓包。
\begin{figure}[H]\centering\includegraphics[width=0.96\textwidth]{截图/03-PPP状态.png}\caption{串口PPP状态和LCP协商。}\end{figure}\clearpage
\section{R2端配置与路由表}
R2作为DTE端不设置DCE时钟，但必须使用相同的PPP封装、正确的/30地址和到10.2.1.0/24的静态路由。R1的show ip route输出应出现到10.2.2.0/24的静态下一跳10.2.12.2；这一步把“串口已经up”与“跨网段有路由”区分开。
\begin{figure}[H]\centering\includegraphics[width=0.96\textwidth]{截图/05-R2串口配置.png}\caption{R2串口DTE配置回显。}\end{figure}\clearpage
\section{路由与抓包证据}
路由表、PC双向ping和PPP抓包共同构成验收链。只看到ping成功不能证明PPP封装正确，因此额外检查链路抓包中的PPP/ICMP记录，并把抓包数量写入结果JSON。
\begin{figure}[H]\centering\includegraphics[width=0.96\textwidth]{截图/06-路由表.png}\caption{R1静态路由表。}\end{figure}\clearpage
\section{结果分析}
历史通过证据中四台设备和三条链路门禁通过，PPP/LCP、clock rate、静态路由和PPP抓包门禁均通过；PC1到10.2.2.2、PC2到10.2.1.2均达到100%（5/5）。抓包用于证明链路上确实出现PPP封装后的ICMP，而不是只检查配置文本。
\begin{figure}[H]\centering\includegraphics[width=0.96\textwidth]{截图/04-静态路由互ping.png}\caption{静态路由和双向互ping结果。}\end{figure}\clearpage
\section{抓包字段与判据}
PPP串口抓包至少应出现链路层PPP帧和上层ICMP请求/应答；PC两端各自位于不同LAN，正式测试前先清理或预热ARP。截图只展示摘要，原始pcap和解析命令仍保留在证据目录。
\begin{figure}[H]\centering\includegraphics[width=0.96\textwidth]{截图/07-PPP抓包.png}\caption{PPP链路抓包验收摘要。}\end{figure}\clearpage
