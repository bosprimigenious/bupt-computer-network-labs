实现状态：自己的13设备、15链路、八业务VLAN拓扑、配置和七个验收阶段已写好。运行状态以evidence内真实result.json为准；没有完整通过证据时为 **NOT READY**。

## 自己的综合拓扑

SW1—SW2—SW3用802.1Q trunk串联，三台交换机均建立VLAN20、30、40、50、60、70、80、90。八台终端每VLAN一台，地址205.161.<VLAN>.2/24，网关205.161.<VLAN>.1。

| 设备/链路 | 作用 |
|---|---|
| SW1 f1/11、f1/12 | PC20、PC30 |
| SW2 f1/11、f1/12 | PC40、PC50 |
| SW3 f1/11～f1/14 | PC60、PC70、PC80、PC90 |
| SW1 f1/1—SW2 f1/1；SW2 f1/2—SW3 f1/1 | 八VLAN跨交换机trunk |
| SW1 f1/2—R1 f1/0 | 单臂路由，子接口20、30、40、50 |
| SW3 f1/2—R2 f1/0 | 物理独立接口、access VLAN60 |
| SW3 f1/3—R2 f2/0 | 物理独立接口、access VLAN70 |
| SW3 f1/4—R2 f3/0 | trunk、子接口80、90 |
| R1 f0/0—R2 f0/0 | 205.161.254.1/30和.2/30；静态路由互联 |

两种互联方法是路由器物理接口连接access VLAN，以及802.1Q子接口单臂路由。VLAN999只作trunk native VLAN且不连接业务主机，业务VLAN均发送带标签帧。默认VLAN1、1002～1005仅为NM-16ESW允许列表的强制保留项，没有业务主机。八个业务VLAN不能删减成小示例。交换机无三层路由，跨VLAN必经R1或R2。

PC20到PC90：PC20发未标记帧 → SW1送VLAN20标签帧至R1 → R1路由转发，跨R1—R2链路帧无VLAN标签 → R2子接口90送VLAN90标签帧至SW3 → SW3 access口去标签送PC90。抓包点同时覆盖这三种链路。

## 七个运行阶段

1. 八VLAN完整双路由器互联，验证56个方向的PC互ping、所有交换机业务VLAN、trunk、两路由器路由表。
2. PC30临时改205.161.20.3但保留VLAN30，PC20的同网段ping必须失败，证明二层隔离。
3. SW1将PC30口改入VLAN20，同交换机同VLAN双向ping必须成功。
4. PC40临时改205.161.20.4、SW2对应口入VLAN20，跨交换机同VLAN双向ping必须成功，验证trunk。
5. PC20和PC30都进VLAN20，保留各自20.2/24、30.2/24。先撤下R1子接口30的地址，再在子接口20增加30.1/24 secondary，通过R1同接口三层转发互ping，验证同一局域网两个IP子网方法一。
6. 删除R1 secondary，PC20/30分别加对端/24网段的出接口静态路由，直接ARP对端，再互ping并检查两端ARP表，验证方法二。PC掩码始终保持/24。
7. 删除两PC额外静态路由，恢复R1子接口30地址和PC30/40原地址/VLAN，再运行56方向全互ping，证明故障实验未留下污染。

每次修改前已声明阶段，所有变更只作用本次临时模拟设备。结束后恢复原配置；失败日志不能删除。需结合VLAN表、路由表及pcap解释标签变化。讲义的思考题“同一局域网两IP网段互通”已配置同接口secondary路由和终端出接口静态路由两个阶段，等待完整重跑验收；本综合验收的两种互联方法实际落在独立物理接口和802.1Q子接口。

## 来源与环境

参考agicy lab4-vlan的vlan database、access/trunk、dot1q子接口配置，并核对Yokumii lab4-vlan task2-2的trunk；自行替换为学号地址、八VLAN和当前接口。来源、许可见[来源说明](../资料/来源说明.md)。三交换机、两路由器均复用本地c3640镜像，八终端复用c2621，不另下载IOS。统一运行入口和证据目录见根README。

不执行PPT中的erase flash；VLAN库在本次独立工作目录生成。先综合配置、再隔离对照、再恢复全量验收；反过来会把临时隔离状态误当综合拓扑失败。能启动或个别ping成功不代表八VLAN聚合门禁通过。

修改顺序必须先撤R1子接口30的IP，再向子接口20加secondary；反过来IOS会拒绝重叠网段。恢复时必须先删secondary，再恢复子接口30。两种方法的PC20物理口抓包留在PC20-access.pcap，阶段时间窗可核对真实ICMP。
