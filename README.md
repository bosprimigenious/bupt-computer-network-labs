## 安装与运行

已使用的环境：macOS arm64、Dynamips 0.2.25-nojit、Python 3.11、TShark 4.6.9。安装脚本使用Homebrew和uv，当前面向macOS；其他平台需自行准备同等工具。

1. 安装Homebrew和uv，准备至少3GB可用磁盘。
2. **自行提供有权使用的Cisco IOS镜像**，按 [_环境/ios/README.md](_环境/ios/README.md) 放置；仓库不分发厂商镜像。
3. 执行：

```sh
sh _环境/setup.sh
./run.sh 实验1
# 同理运行实验2～5
./run.sh 实验6
./run_all.sh
```

实验6需要真实设备或合法镜像提供的12个console端点。将示例复制到未跟踪的 `实验6/endpoints.json` 并配置实际端点；详见实验6说明。无端点时入口应返回NOT READY。单独Cisco预演：

```sh
_环境/.venv/bin/python _环境/lab.py run 实验6/cisco-proxy
```

运行器新建工作目录、启动真实IOS、加载配置、采集输出和抓包，结束时关闭自己启动的进程。生成命令时先输出到新目录核对；部署到共享真实设备前保存原配置，确认接口。课程使用的205.161地址只在隔离实验网内使用。
